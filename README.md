# Nova Elegance — Drop 01

Official site for Nova Elegance: the **No Pain No Gain** tee (Drop 01) and the Drop 02 waitlist.

- Single-file site: everything is in `index.html`.
- Orders and waitlist sign-ups are sent by email through formsubmit.co.
- To change the Drop 02 launch date, edit `DROP2_DATE` in `index.html`.
